# UX & functionality audit: NoAIVerdad (2026-10-13)

Produced by a UX-audit subagent following `.claude/skills/site-ux-audit/`. **Verified independently:**
UX-01 (synthetic fallbacks), UX-03 (Acerca de CSS), UX-05 (keyword counting). All other findings are the
auditor's observations from the running app and code; re-check before acting on them.

**Covered:** map + sidebar (all sections), Dashboard, Acerca de; 375 / 768 / 1440 px; dark + light;
keyboard walk; simulated failure states. **Not covered:** real screen-reader run, real touch scrolling,
200 % zoom (inferred), gradient-button contrast, comment-level Facebook data (needs Meta Content Library).

## Summary
The Meta Ad Library work (ranges, payer, reach %, "indicador, no una prueba") is the credible core. It is
surrounded by fabricated or placeholder content, and the site is unusable below 769 px.

Top 5: (1) backend invents content when sources return nothing, with no UI signal; (2) Dashboard presents
demo/constant numbers as live; (3) "Acerca de" renders blank; (4) map collapses to 0 px and feed can't scroll
on phones/tablets; (5) keyword "análisis" counts search results as "menciones".

**Single change that most improves trust:** never render un-sourced content. Remove the synthetic fallbacks and
the `|| 35`-style chart defaults; label whatever demo data remains "Datos de ejemplo".

## Redesign proposal
**Information architecture:** (1) **Resumen nacional**, the default landing: provenance strip, top advertisers, repeated
messages, KPIs with ranges. (2) **Provincias**: map + feed, with a Mapa/Lista toggle on mobile. (3) **Buscar narrativa**:
keyword + ad-text search with results as links. (4) **Método y fuentes**: the fixed "Acerca de". State (province, section,
period) lives in the URL.

```

[Fuente: Biblioteca de Anuncios de Meta · 8 términos · últimos 120 días · actualizado 13 oct 11:57] [Copiar cita] [CSV]
[Provincia: Todas v] [Periodo: 30 d v]
KPIs: 219 anunciantes | 628 anuncios | USD 36.434 (rango) | top-5 24 %
Top anunciantes (ordenar, buscar)  fila: nombre · paga · rango · impresiones · región · [Ver en Meta]
Mensajes repetidos (indicador, no prueba)  grupo: texto · páginas · financiadores · [ejemplo]
```

**Design tokens:** color roles per theme (`--bg --surface --surface-2 --text --text-muted(≥4.5:1) --border --accent --focus
--warn-* --danger(only for a publisher's own "Falso" rating) --source-*`); type 12/14/16/20/24 px; spacing 4/8/12/16/24/32;
components: card, badge (info/warning/flag-with-tooltip), button, select, one empty/error/loading component with
`role=status`, provenance strip, sticky-header table, KPI tile.

**Migration path:** (1) fix breakers UX-03/04/06/07/08; (2) remove fabrications + label demo UX-01/02/20; (3) a11y + tokens
UX-13…17; (4) provenance strip, citation, deep links UX-10/19; (5) replace keyword feature UX-05; (6) new IA + national landing.

load with a clean console; `lang="es"`; select as an alternative to the map; theme persistence; es-EC number formatting.

## Redesign v6 (2026-10-13)

**Direction:** calmer, data-first interface. One accent color; no emoji in navigation; flat cards; secondary detail behind "Más detalles" / "Ver detalles"; light and dark themes from the same tokens (`frontend/css/styles.css` was rewritten as a small design system).

**Structure:** four views with their own URLs: *Provincias* (`#/mapa/{prov}/{fuente}/{período}`), *Resumen* (`#/resumen/{alcance}/{pestaña}`), *Comparar* (`#/comparar/{a}/{b}/{c}`), *Método* (`#/metodo`). The hero banner was removed; the province picker, source chips and period filter now live in the side panel.

**New functionality:**
- Map: proportional bubbles per province (size = estimated reach, ad count or estimated spend), legend, keyboard-operable. Uses a point per province, not boundaries: the repo's GeoJSON is placeholder shapes, so a shaded map needs a real boundaries dataset first.
- Resumen: tabs (Anunciantes, Mensajes repetidos, Alcance por provincia / Fuentes, Buscar un término); advertiser table with search, sort (column headers, `aria-sort`), expandable rows, "show more".
- Comparar: 2–3 scopes (provinces or national) side by side, top advertisers per scope, advertisers present in all scopes.
- Chart.js removed (HTML bars are accessible and need no dependency).

**Resilience and data integrity found during this work:**
- Meta region data includes places outside Ecuador and spelling variants ("Bolivar"/"Bolívar", "Morona-Santiago"): the map and bars now use the 24 canonical provinces and report the foreign share separately.
- Last good Meta result is saved to `backend/data/ads_snapshot.json` (git-ignored) and shown, marked as saved data, if Meta can't be reached (e.g. expired token).
- Unit tests were writing fake ads to that file; tests now use temporary folders.
- `backend/tools/renovar_token_meta.py` exchanges a fresh short-lived Meta token for a ~60-day one.

**X (Twitter):** integration exists but is off (paid API, no funding yet). The UI labels it "pronto" and explains why. Documented as a future option.

**Calendar:** the Método page states that the seccionales were scheduled for February 2027 in the official calendar and moved to 29 November 2026, and points to the CNE for current dates.
